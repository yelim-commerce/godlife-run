# SUPER 갓생런 — 60초 커리어 성장 플랫포머

고전 횡스크롤 플랫포머 컨셉으로, **60초 동안 화장품·옷을 모아 신입 → 대리 → 과장 → 팀장 → 대표로
성장**하는 게임입니다. 타겟은 30대 직장인 여성, 최종 직급이 곧 할인율입니다 (누구나 당첨).

> 닌텐도의 캐릭터·음악·그래픽은 저작권이 있어 쓰지 않았습니다. 점프·?블록·밟기 같은 **장르 문법만**
> 빌려왔고, 캐릭터와 배경은 코드로 직접 그린 픽셀아트입니다.

## 실행

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

- `?autoplay=1` — 봇이 바로 플레이 (시연·테스트용)
- `?dur=20` — 플레이 시간 변경
- `node --test tests/` — UI·웹훅 계약 테스트

## 조작

| 입력 | 동작 |
|---|---|
| 탭 / Space | 점프 |
| 길게 누르기 | 더 높이 점프 |
| 공중에서 한 번 더 | 2단 점프 |
| ?블록 아래에서 머리로 | 아이템 획득 (💎 레전더리는 여기서만) |
| 방해꾼 위로 착지 | 밟기 +200 · 다시 튀어오름 |

캐릭터는 자동으로 달립니다. 상자에 막히면 멈추므로 시간 손해가 자연스러운 벌칙입니다. 낭떠러지는 없습니다.

## 성장 = 할인

| 단계 | 필요 포인트 | 캐릭터 변화 | 할인 | 증정 |
|---|---|---|---|---|
| 신입 | 0 | 첫 출근룩 · 포니테일 | 5% | 뷰티 샘플 1종 |
| 대리 | 5 | 블라우스 + 레드 립 | 10% | 샘플 3종 |
| 과장 | 12 | 핑크 블레이저 + 핸드백 | 15% | 미니어처 2종 |
| 팀장 | 21 | 트렌치코트 + 선글라스 | 20% | 미니어처 키트 |
| 대표 | 34 | 골드 드레스 + 티아라 | 30% | 정품 풀사이즈 |

- 일반 아이템 +1, 레어(향수·핸드백) +2, 💎 시크릿 주얼리 +3 (획득 시 할인 +5%)
- 코인 10개마다 +1
- 승진할 때마다 **캐릭터가 커지고 옷이 바뀝니다**. 0.7초 멈춰서 이전/새 모습이 번갈아 깜빡이는 변신 연출이 나옵니다.
- 방해꾼(😩 월요병 · 📄 야근 · ⛈️ 스트레스)에 부딪히면 **성장 포인트 −2**. 단, 직급은 내려가지 않습니다.
- 약 25초 지점에 **💸 월급날 러시** 블록이 한 번 나옵니다. 5.5초 동안 무적 + 코인 자석 + 음악 빨라짐.
- 이름·이메일 입력 시 +5% (최대 40%)

봇 실측(데스크톱, 60초): 아이템 38개 · 코인 90 · 성장 49 → 약 44초에 대표 달성.
사람은 이보다 덜 모으므로 보통 과장~팀장, 잘하면 대표입니다. 난이도는 `CONFIG.stages[].min` 으로 조절하세요.

## 🎵 음악 — coupon-pop 과 같은 방식

1순위 **실제 음원 파일**, 실패하면 **WebAudio 합성으로 자동 폴백**합니다.

- `audio/entertainer-v2.mp3` — 스콧 조플린 〈The Entertainer〉(1902). 작곡은 퍼블릭 도메인, 연주는 CC0.
  Wikimedia Commons 원본(5분)에서 앞 96초만 잘라 페이드아웃 처리했습니다 (1.5MB). 자세한 내용은
  [`audio/CREDITS.md`](audio/CREDITS.md).
- **1.5배속 재생** (`AUDIO.rate`) — 음높이는 그대로 두고 템포만 빠르게. 칩튠 폴백도 같은 배속.
- 파일이 없거나 재생이 막히면 같은 곡의 주선율 + 쿵짝 반주를 **칩튠으로 실시간 합성**합니다 (`SONG`).
- 러시 중에는 여기서 1.1배 더 (1.65배).
- 쿠폰팝과 달리 박자 동기화는 없어서 BPM 을 맞출 필요는 없습니다.
- 곡을 바꾸려면 `AUDIO.src` 만 수정하면 됩니다.

## 📧 웹훅 — coupon-pop 과 같은 Make.com 훅

```js
const WEBHOOK = {
  url: 'https://hook.eu1.make.com/iv6p47wuoc7rqnh1fb8884y0n5l6buuf',
  provider: 'make',
  source: 'godlife-run-game',   // 쿠폰팝은 'coupon-pop-game'
  clearStage: 3                 // 팀장 이상이면 cleared=true
};
```

전송 방식도 쿠폰팝과 같습니다: `form-urlencoded`(CORS preflight 회피) → 실패 시 `sendBeacon` →
그래도 실패하면 기기 큐(`godlife_run_outbox`)에 저장해 재시도하고, 페이지를 떠날 때 `sendBeacon` 으로 보냅니다.

**이름·이메일·동의 모두 필수**입니다 (쿠폰팝은 이름이 선택이었음).

| 필드 | 예시 | 비고 |
|---|---|---|
| `date` / `time` | `2026-09-13` / `18:24:07` | KST, 기존 필드 |
| `email` | `kim@company.com` | 기존 필드 |
| `code` | `RUN-8P6G` | 기존 필드 |
| `score` | `8420` | 기존 필드 |
| `cleared` | `true` | 팀장 이상 |
| `discount` | `25` | 최종 할인율 |
| `agreedAt` | ISO 8601 | |
| `source` | `godlife-run-game` | **게임 구분용** |
| `name` | `김지은` | |
| `stage` | `LV.4 팀장` | 이 게임 전용 |
| `growth` / `items` / `kinds` / `coins` | `26` / `21` / `9` / `48` | 이 게임 전용 |
| `collected` | `벨벳 립스틱 x3, 레드 힐 x1, ...` | 이 게임 전용 |

Make 시나리오에 새 필드를 매핑하지 않아도 기존 흐름은 그대로 동작합니다.

## 브랜드 바꾸기

`game.js` 맨 위 `CONFIG` 에서 수정합니다: 아이템(`products`: 이모지·이름·색·희귀도), 단계와 할인(`stages`),
월드 색(`worlds`), 속도·물리(`runSpeedStart/End`, `physics`), 벌칙(`hurt`).
